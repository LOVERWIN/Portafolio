# Erwin Santiago - Portafolio

Este es el código fuente del portafolio web de Erwin Santiago, un programador web apasionado por la tecnología.

## Descripción

Este proyecto es una página web estática que muestra el portafolio de Erwin Santiago. Incluye una sección sobre él, sus habilidades, una lista de sus proyectos y un formulario de contacto.

## Características

*   **Diseño adaptable:** El sitio web está diseñado para ser visto en diferentes dispositivos, desde computadoras de escritorio hasta teléfonos móviles.
*   **Secciones:**
    *   **Inicio:** Una sección de bienvenida con una imagen de fondo.
    *   **Acerca:** Una breve biografía y una lista de habilidades con barras de progreso.
    *   **Portafolio:** Una galería de proyectos con descripciones y enlaces a demostraciones en video.
    *   **Contacto:** Tarjetas de contacto con información de ubicación, teléfono, correo electrónico y redes sociales, junto con un formulario de contacto funcional.
*   **Modales:** Los proyectos en la sección de portafolio se abren en ventanas modales para mostrar más detalles.
*   **Formulario de contacto:** Un formulario de contacto que utiliza FormSubmit.co para enviar correos electrónicos.

## Tecnologías Utilizadas

*   HTML5
*   CSS3
*   JavaScript (ES6)

## Cómo Utilizar

1.  Clona este repositorio: `git clone <URL_DEL_REPOSITORIO>`
2.  Abre el archivo `index.html` en tu navegador web.

¡Eso es todo! Ahora deberías poder ver el portafolio de Erwin Santiago en tu navegador.
